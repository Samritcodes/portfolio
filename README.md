# 🌌 Celestial Star System Portfolio — Samrit Kumar Bhutia

> An Apple-grade, immersive 3D interactive celestial portfolio engineered with Three.js, GSAP, WebGL shaders, Tailwind CSS, and Web Audio API synthesis.

---

## 🌟 Concept & Architecture

The portfolio models Samrit Kumar Bhutia's software and AI engineering universe as an interactive **3D Solar System**:

- ☀️ **Central Stellar Core (`SOLIS // SAMRIT`)**: The origin star representing core engineering identity, architectural pillars, GitHub metrics, and professional overview.
- 🪐 **Orbit 01: `AGRISENSE PRIME` (Flagship AI)**: Ringed emerald gas giant dedicated to **AgriSense AI** (Crop Pathology Computer Vision & Deep Learning Engine with <200ms ResNet inference across 28 pathologies).
- 💎 **Orbit 02: `CODESPRINT ATLAS` (Autonomous Systems)**: Sapphire/violet crystalline world dedicated to **CodeSprint AI** (Autonomous daily coding agent pipeline with GitHub Actions CI/CD and DSA problem reviews).
- 🌍 **Orbit 03: `TERRA GAIA` (Full-Stack Suite)**: Earth-like terrestrial world with orbiting moons showcasing **EcoTrack** (gamified carbon tracker), **AI Resume Checker** (Google Gemini ATS analyzer), and **Session & Subscription Manager**.
- ⚡ **Orbit 04: `ASTRA ARSENAL` (Skill Matrix)**: Molten plasma world showcasing proficiency in Python, React 19, TypeScript, FastAPI, TensorFlow, Node.js, Three.js, Docker, and MongoDB.
- 📡 **Orbit 05: `SIGNAL BEACON` (Comms & Shell)**: Quantum pulsar world featuring dual magnetic energy beams, direct transmission dispatch, and an **interactive holographic terminal emulator (`help`, `projects`, `skills`, `bio`, `warp <0-5>`, `contact`)**.

---

## ✨ Standout Features

- **Apple-Grade Camera Kinematics**: Clicking any star or planet initiates a silky smooth GSAP camera fly-through with damping and dynamic framing against the cosmic backdrop.
- **100% Procedural Graphics**: Planetary textures (gas bands, terrestrial continents, digital cyber grids, rings, atmospheres) are dynamically synthesized via HTML5 Offscreen Canvas — zero external image dependencies, zero CORS errors, instant loading.
- **Procedural Audio Synthesizer**: Web Audio API binaural 432Hz deep-space drone, resonant acoustic UI blips, and hyper-warp whoosh effects.
- **Sci-Fi HUD & Holographic Telemetry**:
  - Live UTC Mission Clock.
  - Interactive Minimap Radar with real-time sector scanner.
  - 3D Projected Target Tooltips that track orbital coordinates in screen space.
  - Dynamic Island Celestial Dock for instantaneous orbit jumping.
  - Holographic Slide-in Dossier Drawer with glassmorphic depth (`backdrop-filter: blur(28px)`).
- **Keyboard Navigation**:
  - `0` - `5`: Instant hyper-warp to any orbital body.
  - `Space` / `Esc`: Return to orbital system overview.
  - `M`: Toggle ambient cosmic synthesizer.
